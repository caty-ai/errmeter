# Visual rule

Communicate one message: “a shout that is never lost.” Use a flat midnight-blue background with generous empty space, pale lettering, and one warm amber signal traveling along a thin blue line through four equally sized rounded nodes labeled emit, spool, sink, and watch. Keep node borders, corner radii, line weights, and label placement identical; make the errmeter wordmark the first visual anchor, the tagline its quieter companion, and the disk-first route the only diagram. Use no version, date, URL, decorative texture, or embedded metadata. The social preview is a proportional reduction of the approved hero.
